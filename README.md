# 火影忍者手游 - 替身术计时器

一个轻量级的桌面悬浮倒计时工具，用于火影忍者手游中**替身术**的冷却计时。

## 功能特性

- **悬浮窗显示** — 无边框透明窗口，始终置顶，不遮挡游戏画面
- **快捷键触发** — 按下 `Q` 键立即启动 13.5 秒倒计时
- **窗口可拖拽** — 左键拖动调整位置，松开自动保存
- **位置记忆** — 退出后记住窗口位置，下次启动自动恢复
- **右键退出** — 右键点击即可关闭程序

## 运行环境

- Python 3.7+
- Windows（依赖 `tkinter` 透明窗口特性）

## 安装依赖

```bash
pip install pynput
```

> `tkinter` 为 Python 内置模块，通常无需额外安装。

## 使用方法

```bash
python simple_timer.py
```

启动后屏幕会出现一个悬浮数字 **0**，按下键盘 `Q` 键开始 13.5 秒倒计时。

| 操作 | 说明 |
|------|------|
| `Q` 键 | 启动 / 重新启动倒计时 |
| 左键拖拽 | 移动窗口位置 |
| 右键点击 | 退出程序 |
